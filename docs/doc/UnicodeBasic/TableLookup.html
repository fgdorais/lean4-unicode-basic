              def Unicode.lookupSpecialCasing (c : UInt32) :
              List UInt32 × List UInt32 × List UInt32

              Get full case mappings of a code point using lookup table

              Returns (l, t, u) where l is the full lowercase mapping, or [] if it agrees with the simple lowercase mapping, and similarly t for titlecase and u for uppercase. Only unconditional mappings are included.
